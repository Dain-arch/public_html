# DAIN'S SPACE --- 개인 포트폴리오 웹사이트 기획서

## 1. 프로젝트 개요

-   **프로젝트명:** DAIN'S SPACE
-   **목적:** 대학생활과 학업 경험, 전공 및 복수전공 활동, 프로젝트,
    개인적인 관심사를 정리해 소개하는 개인 포트폴리오 웹사이트 제작
-   **사용 목적:** 대학 과제 제출 및 개인 포트폴리오
-   **주요 방문자:** 담당 교수, 대학 관계자, 포트폴리오를 확인하는 일반
    방문자
-   **콘텐츠 언어:** 한국어
-   **메뉴 및 주요 디자인 문구:** 영어
-   **제작 범위:** 이번 단계에서는 웹사이트의 기획과 설계만 진행한다.
    실제 웹사이트 구현은 별도 단계로 진행한다.

## 2. 웹사이트의 핵심 방향

이 웹사이트는 특정 직업이나 진로를 확정적으로 내세우기보다, 대학생
이다인의 현재 모습과 대학생활을 폭넓게 보여주는 포트폴리오를 지향한다.

식품영양학과 전공과 경영학과 복수전공을 함께 소개하고,
학업·프로젝트·대학생활·개인적인 취향과 일상을 자연스럽게 연결한다.
진로는 아직 탐색 중인 상태이므로 영양사와 식품기업의 마케팅·홍보·브랜드
관련 분야에 대한 관심을 소개하되, 확정된 진로처럼 표현하지 않는다.

### 핵심 콘셉트

-   차분하면서도 세련된 분위기
-   미니멀하고 현대적인 디자인
-   부드럽고 밝은 색감
-   디자인과 콘텐츠가 균형을 이루는 구성
-   실제 경험과 자료를 중심으로 한 진정성 있는 포트폴리오

## 4. 사이트맵 및 내비게이션

상단 메뉴는 영어로 표시하고, 각 페이지의 실제 설명과 콘텐츠는 한국어로
작성한다.

1.  **Home** --- 홈페이지
2.  **About Me** --- 자기소개
3.  **University** --- 대학생활 및 학업 활동
4.  **Projects** --- 프로젝트 및 과제
5.  **Interests** --- 개인적인 관심사와 일상
6.  **Contact** --- 연락처 및 SNS

홈페이지는 전체 내용을 간략히 소개하고, 각 메뉴를 선택하면 해당 내용을
자세히 볼 수 있는 하이브리드 구조로 설계한다. 즉, 홈페이지 요약과 별도의
상세 페이지를 함께 제공하는 다중 페이지 방식이다.

## 5. 페이지별 상세 기획

### 5.1 Home

첫 화면에서 웹사이트의 주인과 전체적인 성격을 빠르게 파악할 수 있도록
한다.

**히어로 영역** - 왼쪽: `HELLO, I'M DAIN` - 이름: 이다인 (Dain Lee) -
전공: 식품영양학과 - 복수전공: 경영학과 - 학년: 4학년 - 짧은 소개 문구:\
"작은 관심과 경험을 모아 나만의 이야기를 만들어 가는 중입니다." -
오른쪽: 실제 얼굴 사진 대신 AI로 제작한 프로필 일러스트

**환영 문구** - "DAIN'S SPACE에 오신 것을 환영합니다."

**요약 카드** - About Me - University - Projects - Interests

각 카드는 해당 상세 페이지로 이동하도록 한다.

**홈페이지에 포함하지 않을 항목** - 최근 활동 목록은 홈페이지에 별도로
표시하지 않는다.

### 5.2 About Me

현재의 자신을 소개하는 페이지로 구성한다. 성장 과정이나 대학생활 중
변화는 이 페이지의 핵심 내용으로 다루지 않고, 현재의 성격과 가치관,
관심사를 중심으로 작성한다.

포함할 항목: - 기본 프로필 - 자기소개 - 성격 및 강점·보완점 - 중요하게
생각하는 가치 - 개인적인 관심사

성격과 강점·보완점은 **키워드와 구체적인 설명을 함께 제시하는 방식**으로
구성한다.

실제 성격, 가치관, 경험은 사용자가 제공한 내용을 바탕으로 작성한다.
확인되지 않은 성격이나 경험을 임의로 만들어 넣지 않는다. 정보가 아직
없는 항목은 작성 안내 또는 임시 입력 영역으로 둔다.

### 5.3 University

대학생활과 학업 경험을 종합적으로 소개한다.

구성 항목: - **Academic Life:** 전공 및 복수전공 수업, 학습 경험 -
**Activities:** 교내·외 활동 및 참여 경험 - **Growth:** 대학생활에서
경험하고 배운 점 - **Certificates:** 자격증, 자격시험 및 준비 과정

실제 수강 과목, 활동, 자격 및 시험 관련 내용은 사용자가 확인해 제공한
정보만 반영한다. 내용이 없는 영역은 빈 입력 영역이나 작성 안내로
표시한다.

### 5.4 Projects

프로젝트를 단순 나열하는 데 그치지 않고, 주제와 수행 과정, 역할 및
결과를 확인할 수 있도록 구성한다.

**목록 화면** - 카드형 레이아웃 - 프로젝트 대표 이미지 - 프로젝트명 -
간단한 요약 - 전공 및 활동 유형 태그

**표시 순서** 1. 대표 프로젝트를 상단에 배치 2. 그 아래 나머지
프로젝트를 최신순으로 정렬

대표 프로젝트는 실제 프로젝트 자료를 확인한 뒤 선정한다.

**분류 체계** - 전공: 식품영양학과 / 경영학과 - 활동 유형: 개인 과제 /
팀 프로젝트 - 실제 과목명은 필요할 경우 추가 태그로 표시

전공과 활동 유형을 함께 활용해 프로젝트를 분류한다.

**검색 및 필터** - 프로젝트명 또는 키워드 검색 - 전공별 필터 - 활동
유형별 필터

**프로젝트 상세 화면** - 프로젝트 개요 및 목적 - 진행 과정 - 본인의
역할 - 결과 및 느낀 점 - 관련 사진, 발표자료 등

상세 페이지는 텍스트와 이미지 자료를 함께 배치한다. 실제 프로젝트 내용과
본인의 기여를 확인한 뒤 작성하며, 역할이나 성과를 임의로 부풀리지
않는다.

### 5.5 Interests

전공이나 진로 관심보다는 개인적인 취향과 일상을 보여주는 페이지로
구성한다.

포함할 항목: - Hobbies --- 취미 - Favorites --- 좋아하는 음식, 음악,
장소 등 - Daily Life --- 일상 - Photo Gallery --- 사진 갤러리

**갤러리 구성** - 주제별 앨범과 그리드 레이아웃을 함께 사용 - 앨범 예시:
Daily Life, Food, Travel, Memories - 사진을 클릭하면 확대 보기(lightbox)
제공 - 날짜, 장소, 설명이 제공된 사진은 확대 화면에서 추가 정보 표시

사진은 사용자가 제공한 실제 사진을 중심으로 사용한다.

### 5.6 Contact

방문자가 공개된 연락 경로를 확인할 수 있는 페이지다.

포함할 항목: - 이메일 - SNS 링크

별도의 문의 양식이나 방명록, 댓글, 방문자 메시지 기능은 만들지 않는다.
이메일 주소와 SNS 계정은 공개 여부를 결정하기 전까지 임시 문구 또는
빈칸으로 둔다.

## 7. 반응형 및 인터랙션

### 반응형 지원

PC, 노트북, 태블릿, 모바일에서 모두 사용할 수 있도록 반응형으로
설계한다.

-   **PC/노트북:** 넓은 화면을 활용한 좌우 배치와 카드형 구성
-   **태블릿:** 카드 간격과 콘텐츠 폭 조정
-   **모바일:** 세로형 레이아웃, 모바일 메뉴, 터치에 적합한 버튼 크기

### 애니메이션 및 상호작용

과도한 효과 없이 다음과 같은 미세한 효과를 적용한다. - 스크롤 시
부드러운 페이드인 - 버튼 및 메뉴의 색상 전환 - 프로젝트 카드에 마우스를
올렸을 때 약한 확대 효과 - 페이지 이동 시 부드러운 전환 - 사진 클릭 시
확대 보기

애니메이션은 콘텐츠를 방해하지 않도록 절제한다. 사용자의 움직임 줄이기
설정을 존중하는 방식도 고려한다.

## 8. 콘텐츠 관리 방식

별도의 관리자 대시보드는 만들지 않는다.

디자인과 콘텐츠를 분리하고, 간단한 데이터 파일을 수정해
자기소개·프로젝트·갤러리 내용을 업데이트할 수 있도록 한다.

예상 콘텐츠 관리 방식: - 자기소개: 별도 데이터 파일 - 프로젝트:
프로젝트별 정보 데이터와 이미지 파일 - 갤러리: 사진 파일과 설명 데이터 -
디자인 및 페이지 구조: HTML/CSS/JavaScript 파일

콘텐츠를 수정하기 위해 전체 웹사이트 코드를 매번 변경하지 않아도 되는
구조를 목표로 한다.

## 9. 기술 구성

권장 기술: - HTML - CSS - JavaScript - JSON 등 간단한 데이터 파일

별도의 프레임워크 없이 구현하는 정적 웹사이트를 우선한다. 현재 기획
범위에서는 React나 Next.js와 같은 프레임워크가 필수적이지 않다.

### 예상 폴더 구조

``` text
dain-space/
```

위 구조는 구현 단계에서 참고할 제안이며, 실제 페이지 수와 데이터 구성에
따라 조정할 수 있다.

## 10. 이미지 및 자료 사용 원칙

이미지 출처를 다음과 같이 구분한다.

1.  **AI 생성 이미지:** 홈페이지 프로필 일러스트
2.  **직접 촬영한 사진:** 대학생활, 음식, 여행, 일상 등
3.  **무료 이미지:** 배경 또는 장식 목적. 사용 전 라이선스와 이용 조건
    확인
4.  **프로젝트 자료:** 사용자가 직접 제공한 과제 이미지, 발표자료,
    결과물

타인의 이미지나 프로젝트 자료를 사용할 때는 저작권과 공개 가능 여부를
확인한다. 프로젝트에 포함된 타인의 개인정보나 민감한 정보는 공개하지
않는다.

## 11. 방문자 통계

홈페이지에 방문자 수를 크게 표시하는 카운터는 두지 않는다.

별도의 분석 도구를 이용해 다음과 같은 통계를 확인하는 방향으로
계획한다. - 전체 방문 수 - 페이지 조회 수 - 방문 추이 - 기기 유형

분석 도구와 설정은 구현 단계에서 결정한다. 실제 수집 항목, 쿠키 사용
여부, 보관 기간 및 개인정보 처리 방식은 선택한 서비스의 정책과 설정을
확인한 뒤 결정한다. 필요한 경우 방문자에게 관련 내용을 안내한다.

## 12. 접근성 및 사용성 고려사항

-   본문과 배경의 명도 대비를 충분히 확보한다.
-   이미지에는 의미를 전달하는 대체 텍스트를 제공한다.
-   키보드만으로도 주요 메뉴와 기능을 이용할 수 있도록 한다.
-   링크와 버튼은 기능을 이해할 수 있는 명확한 이름을 사용한다.
-   모바일에서 글자와 터치 영역이 지나치게 작아지지 않도록 한다.
-   애니메이션이 불편한 방문자를 고려한다.
-   메뉴 구조와 페이지 제목을 일관되게 유지한다.

## 13. 검색 및 공유 준비

교수에게 웹사이트 URL을 제출해야 하므로 온라인 공개와 링크 접근을
고려한다.

-   각 페이지에 명확한 제목과 설명을 설정한다.
-   공유 시 사이트 이름과 소개가 자연스럽게 표시되도록 기본 메타 정보를
    준비한다.
-   공개 후 로그아웃 상태 또는 다른 브라우저에서도 링크가 열리는지
    확인한다.
-   제출 전에 모든 메뉴와 내부 링크가 정상 작동하는지 점검한다.

## 14. 배포 계획

**배포 서비스 후보:** Netlify

-   먼저 로컬 환경에서 제작하고 테스트한다.
-   완성 후 Netlify를 이용해 온라인에 배포한다.
-   초기에는 무료 기본 주소를 사용한다.
-   필요할 경우 추후 개인 도메인을 검토한다.

특정 요금이나 무료 제공 범위는 실제 배포 시점의 서비스 정책을 확인한다.

## 15. 제작 및 검수 단계

### 1단계: 콘텐츠 준비

-   자기소개와 프로필 정보 정리
-   대학생활 및 학업 활동 정리
-   실제 프로젝트와 대표 프로젝트 선정
-   갤러리 사진 및 설명 준비
-   이메일과 SNS 공개 여부 결정
-   학교명 공개 여부 결정

### 2단계: 기본 구조 제작

-   공통 내비게이션과 푸터
-   홈페이지 히어로 영역
-   각 상세 페이지의 기본 레이아웃
-   공통 색상, 서체, 간격 규칙 적용

### 3단계: 기능 구현

-   프로젝트 검색 및 필터
-   프로젝트 상세 화면
-   사진 갤러리 및 확대 보기
-   반응형 메뉴
-   페이지 전환 및 미세 애니메이션

### 4단계: 반응형 및 접근성 점검

-   메뉴와 버튼 작동 확인
-   이미지 대체 텍스트 및 키보드 접근 확인
-   가독성과 레이아웃 점검

### 5단계: 배포 및 제출

-   공개 URL 확인
-   모든 페이지와 링크 최종 점검
-   교수에게 제출할 URL 복사 및 접속 테스트

## 16. 초기 제작 시 임시 콘텐츠 처리

아직 실제 자료가 정해지지 않은 부분은 다음 원칙으로 처리한다.

-   실제 내용이 필요한 곳은 빈칸이나 입력 안내로 둔다.
-   디자인을 확인하는 데 필요한 경우에만 일부 예시 콘텐츠를 사용한다.
-   예시 콘텐츠에는 실제 경험이 아닌 임시 예시임을 명확히 표시한다.
-   실제 프로젝트, 성격, 활동, 수상 및 자격 내용을 임의로 만들어 넣지
    않는다.
-   학교명, 이메일, SNS 등 공개 여부가 미정인 정보는 placeholder로 둔다.

## 17. 이번 기획 단계에서 구현하지 않을 항목

-   실제 웹사이트 코드 작성 및 배포
-   관리자 대시보드
-   방명록, 댓글, 방문자 메시지 기능
-   홈페이지 방문자 수 카운터
-   다크 모드
-   확정되지 않은 개인정보 및 실제 경험의 임의 입력

## 18. 최종 방향 요약

DAIN'S SPACE는 식품영양학과 전공과 경영학과 복수전공을 바탕으로
대학생활, 학업 경험, 프로젝트, 개인적인 관심사를 소개하는 개인
포트폴리오 웹사이트다.

화이트와 베이비핑크를 중심으로 한 미니멀하고 현대적인 디자인, 세리프
제목과 산세리프 본문, 프로필 일러스트, 한국어 콘텐츠와 영어 메뉴를
사용한다. 홈페이지는 전체 내용을 요약하고 각 메뉴에서 상세 내용을 확인할
수 있도록 구성한다.

프로젝트는 대표 프로젝트를 먼저 보여준 뒤 나머지를 최신순으로 정렬하며,
전공과 활동 유형에 따라 검색·필터링할 수 있도록 한다. Interests 페이지는
개인 취향과 일상 사진 중심으로 구성한다. 콘텐츠는 데이터 파일로 분리해
쉽게 수정할 수 있도록 하고, 정적 웹사이트로 제작한 뒤 Netlify에 배포해
교수에게 제출할 공개 URL을 마련한다.

**중요:** 이 문서는 웹사이트 제작을 위한 기획서다. 실제 구현은 이 기획을
검토하고 필요한 콘텐츠와 자료를 준비한 다음 별도 단계에서 진행한다.
